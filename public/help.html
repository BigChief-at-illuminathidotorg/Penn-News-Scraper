For your team

Search headlines or sources, or choose a section or publication week. All dates shows every saved article. Select a source name in the left index to open its dedicated archive page; the small number beside it jumps to that source on the monitor. As you scroll, arrows at the bottom of the screen change weeks and take you back to the top.

Each source page searches its saved stories by words and date. To look further back, a repository editor can open the archive job on GitHub, choose Run workflow, and enter the source ID and an optional earliest date. The archive page explains where that job stopped. It follows older pages when available, but some sites do not expose their whole history. The search filters do not start a new scrape.

Check the box beside any headline, then choose Export to copy those stories or download them as a text file, grouped by source the way the For Consideration email lists them. Import opens a saved JSON snapshot. Night mode and Compact view change how the page looks.

Check for updates

Choose Check for updates to see the latest published news and open the collection workflow on GitHub. If you have access to the repository, sign in and choose Run workflow, then Run workflow again. Return to this page; it checks for published results every five minutes. GitHub also collects at 11:17 and 17:17 UTC on weekdays.

Manage sources

Choose View all sources to search addresses and warnings. Manage source list opens a form to add a source, edit a URL, add additional news pages, or remove a source. Save each form to your draft, choose Copy updated list, then open GitHub. Select the entire file, paste, and choose Commit changes. Your GitHub account needs permission to edit Penn-News-Scraper. The collection starts automatically after the commit.

If something fails

Choose Check job status, then Open GitHub. The last published news stays readable. A successful job does not mean every source succeeded: View all sources shows each source’s warning. A newly added or changed address shows Awaiting collection until its first collection is published.

← Open the monitor

For your team

Search headlines or sources, or choose a section or publication week. All dates shows every saved article. Use the index on the left to jump to any school or site. As you scroll, arrows at the bottom of the screen change weeks and take you back to the top.

Check the box beside any headline, then choose Export to copy those stories or download them as a text file, grouped by source the way the For Consideration email lists them. Import opens a saved JSON snapshot. Night mode and Compact view change how the page looks.

Check for updates

Check for updates starts a new collection on GitHub and loads the results when they are published, usually within five minutes. If a collection is already running, it waits for that one. If one finished in the last ten minutes, it simply shows those results. The first time, it asks for the team passcode; your browser can remember it.

GitHub also collects on its own at 11:17 and 17:17 UTC on weekdays.

Add, edit or remove a source

Choose View all sources. Use Add a source, or Edit or Remove beside any source. You need the name, the school or unit, and the address of the news page. If a source spreads its news over more than one page, add the other addresses under More pages. Each change is saved to GitHub and starts a new collection, so it shows up in about five minutes.

A new source is read with the collector’s general rules. If it comes back with a warning, the page may need a rule of its own: send the address and the warning to whoever looks after the collector.

One-time setup (for the owner)

Changes from the monitor go through a small helper that runs with the site on Cloudflare. It needs a GitHub key, which only the repository’s owner can make. Until it has one, the monitor still works but only shows published results.

  1. Open the pre-filled key form on GitHub. The name, expiry and permissions are already filled in. Under Repository access, choose Only select repositories, then Penn-News-Scraper. Choose Generate token and copy the key.
  2. Open the repository’s New secret page. Name the secret MONITOR_GITHUB_TOKEN, paste the key, and choose Add secret.
  3. The next collection hands the key to the site. To use it right away, open Collect and publish Penn news and choose Run workflow.

The key lasts a year. To renew it, make a new one the same way and replace the secret. Never paste the key into the monitor, an email or a chat.

The team passcode comes from the monitor’s owner. To change it, add a repository secret named MONITOR_PASSCODE with the new passcode, at least 12 characters long. It applies from the next collection, and everyone enters it once.

If something fails

Choose Check job status, then Open GitHub. The last published news stays readable. A successful job does not mean every source succeeded: View all sources shows each source’s warning. A newly added or changed address shows Awaiting collection until its first collection is published.

For your team

Open the monitor and search headlines or sources. Choose a section or publication week. All dates shows every saved article. Import opens a saved JSON snapshot; Export saves your current collection. Night mode and Compact view are available.

Where updates come from

GitHub collects news at 11:17 and 17:17 UTC on weekdays. The monitor checks for published data every five minutes and uses the newer collection from GitHub or this deployment. Check for updates retrieves published results; it does not start the scraper. Imported snapshots pause updates until you choose Return to online collection.

The collection time means when a collection was prepared. Each source has its own last-check time and warning. A newly added or changed address shows Awaiting collection until the worker publishes results for it. Sources that block the collector may still need attention.

Update the GitHub worker once

  1. Open your prepared GitHub update titled “Restore collection and add Monitor 3.1 with 64 sources”.
  2. When its checks pass, click Merge pull request, then Confirm merge.
  3. Open Collect and publish Penn news. Merging starts the job automatically. Open the newest run to see its progress.
  4. After it succeeds, open the monitor and choose Check for updates. Check job status shows the latest GitHub result separately from the collection time.

This update installs the monitor and collector together. No hidden-folder upload, local Python, or new API token is needed. Existing GitHub secrets are used. The worker targets the existing Cloudflare project, production branch.

Optional manual monitor deployment

This ZIP contains the website files at its top level. Upload it to the existing penn-news-monitor Cloudflare Pages project as a production deployment. The packaged collection is a saved fallback, not a new scrape. Merge the GitHub update above too, so scheduled jobs publish this same monitor rather than overwrite it with an older version.

If an update fails

Choose Check job status, then Open GitHub. The last published news stays readable. A successful job does not guarantee every source succeeded: use View all sources to review warnings. Do not paste API tokens into the monitor or chat.

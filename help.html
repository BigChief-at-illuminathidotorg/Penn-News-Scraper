Your daily news check

Open the monitor, search for a topic or desk, and click a headline to read the original story. Use the week arrows to see other publication weeks.

The online collector is configured to check sources twice each weekday once the owner activates it. “Check for updates” loads the latest completed collection; it does not start a new scrape. Leaving the page open checks for published results every five minutes.

Import a saved snapshot

Click Import and choose a news snapshot JSON file. It changes only your browser view and pauses automatic updates so your imported results stay visible. Click Check for updates to return to the shared online collection. Export saves your current snapshot.

When something looks wrong

Check the latest collection time. If updates are overdue, contact the monitor owner. A source warning means that its latest check failed or found no usable articles. Earlier results may remain visible with their original update time. An empty week is not proof that a department published nothing.

Adding or changing a source

Send the monitor owner the department name and its news-page address. Source changes must be made centrally so everyone sees the same list. Browser settings such as theme and filters are personal.

This version collects news pages, not separate magazine streams. It is a monitoring aid, not a complete historical archive.
